# Prior data audit evidence

These aggregate JSON reports were copied from the previously delivered v0.4 starter archive on 2026-10-15. They document real earlier snapshot runs, not a rerun performed while publishing this repository. Raw records, identifiers, individual image hashes and split manifests are supplied separately through the authorized handoff.

- `austin_current/audit.json`, `austin_legacy/audit.json`: source quality, episode status and fixed split counts.
- `petfinder_adoption/audit.json`: schema/missingness, eligible cohort, image counts and split results.
- `oxford/image_audit.json`: annotated-image/decode and candidate-duplicate audit.
- `stanford_dogs/audit.json`: image/class counts, exclusions and filtered benchmark limitations.

Historical archive-size or hash values identify the run artifact at the recorded step. A later repackaged ZIP may differ; use the checksum manifest shipped with the exact package when verifying bytes. This historical directory predates Pawpularity acquisition. Its real October 16 audit is in `../pawpularity_2026-10-16/`.
