## 给组员的使用顺序

1. 克隆仓库，安装依赖，运行 `python -m unittest discover -v`。
2. 从 Sam 的单独交接取得自己有权访问的数据包；不要把 ZIP/CSV/图片上传到公开仓库。
3. 按 [RUNBOOK.md](RUNBOOK.md) 指定原始文件及既有拆分清单路径。首次拿到矩阵训练时，先核对 `matrix_row` 与标签顺序。
4. 固定现有拆分跑 baseline，再用验证集讨论阈值；暂时不要用 test 反复调模型。
